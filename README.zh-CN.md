# Budapest 音乐字体介绍

Budapest 音乐字体，基于**布达佩斯音乐出版社** (Editio Musica Budapest, EMB) 出版的**李斯特**作品全集中所使用的手工制谱字体，经由数字化处理而制成，以粗重的音符符头和较细的线条为主要特色。

本字体采用 [SIL Open Font License 1.1](LICENSE.md) 授权，任何个人、企业均可免费使用，包括商用，无需另行通知字体原作者。

---

**注**：EMB 李斯特全集也存在部分电脑制作的乐谱，使用的字体为 Pertrucci, 该字体也是制谱软件 Finale 的内置字体之一。本字体模仿的是手工制作的乐谱字体。
